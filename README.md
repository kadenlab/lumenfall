# 灯の継承者 — Lumenfall

ドット絵キャラクターと立体背景で描く、オリジナル短編ファンタジーRPG（Chapter 1・2・3＋灯の試練）。
Chapter 1の町・丘・遺跡に加え、Chapter 2の霧港・礼拝堂、Chapter 3の雪原・集落・旧都・地下聖堂まで遊べます。

## Chapter 3「雪に閉ざされた灯」（1.4.0）

Chapter 2クリア後、冒険メニュー → **チャプターの記録 → Chapter 3** を選びます。更新前にChapter 2をクリアした記録も「つづきから」で自動解放します。セーブ削除や再クリアは不要です。灯の試練は必須ではありません。

白霧の雪原 → 凍灯の集落 → 凍れる番人 → 凍れる旧都 → 凍灯聖堂 → 氷葬の灯守 → 大灯復活 → Chapter 3 Complete。ミナの「次は雪の山」を直接引き継ぐ本編です。

## Chapter 2への出発

Chapter 1をクリアし、クリア画面または町の「Chapter 2 · 霧の港へ」を選んでください。クリア済みの方は「つづきから」で出発できます。冒険メニューの「チャプターの記録」から章を行き来できます。Chapter 2の内容・攻略・変更点は [Chapter 2ガイド](docs-dev/CHAPTER-2.md) を参照してください。

## 操作とセーブ

- WASD / 矢印キー：移動。E / Space：話す・調べる。Esc：メニュー。
- 地面をクリック：指定地点へ自動移動。「次の目的地」の案内ボタンでも自動移動できます。
- スマートフォン：左の移動スティック。指を離すと停止します。案内ボタンによる自動移動もスティック操作で中断できます。
- 戦闘：画面右下のコマンドを選択。
- セーブ：冒険メニューから記録。移動や戦闘後などにも自動保存。

記録はそのブラウザ・公開URLのローカルストレージに保存されます。別端末・別ドメイン・別ブラウザには自動移行しません。

## 最適化版の更新内容

- 描画解像度をPCで約160万画素、スマホで約95万画素以内に制御。自動設定は継続的な負荷を見て調整します。
- 不透明な建物・草木・地形を材質と区画ごとにまとめて描画します。
- 影は1024pxで、太陽の位置に合わせて最大毎秒2回更新。遺跡は静的な影を再利用します。
- 水面反射は最大毎秒15回（戦闘時10回）、川384pxを維持し、噴水のReflectorを廃止。複数の水面が互いを再描画する処理を止めました。
- 同時に計算する局所ライトをPC6灯・スマホ4灯に制限。窓や松明の発光は残しています。
- 波と草の揺れ、塵、魔法の飛散粒子をGPU側で計算。水面の法線をCPUで毎フレーム作り直す処理をなくしました。
- 発光のぼかしは低い解像度で処理。ティルトシフトと霧、ボスの画面振動・光・ヒットストップを維持しています。
- 同じ内容のUI更新を省略し、非表示タブの描画を停止。互換描画のバッファも再利用します。
- スマホ左上は地名＋短い目的地ボタンに整理。英語の地名、補足文、行程表示を省略しました。
- 冒険メニューで自動／高画質／軽量を切り替え、FPSと描画方式を確認できます。

- スマホはpixel ratio上限1.2、PCは1.25。スマホの影はPCFShadowMap、PCは従来のPCFSoftShadowMapを維持。
- 噴水の水面は16頂点、川は429頂点。波の時刻更新は2描画フレームに1回。
- Chapter 1移行後も旧セーブを読み込めます。新保存はversion 2、旧データは元のキーに残ります。

## 編集・再ビルド

Node.js 22.18以降が必要です。

```sh
npm ci
npm run dev
```

Chapter 1の内容は `app/chapters/chapter-1/`、共通処理は `app/game.ts`・`app/systems/` にあります。チャプター追加は [開発ガイド](docs-dev/CHAPTERS.md)、変更点・検証結果は [最適化記録](docs-dev/OPTIMIZATION.md) を参照してください。

```sh
npm test
npm run build
```

変更後は更新された `docs/` もコミットしてください。GitHub Pagesはそのビルド済みファイルを配信します。HTMLをダブルクリックしての起動は想定していません。

WebGLが利用できない環境では簡易描画に切り替わり、反射・影・発光などの表現が制限されます。フォントはGoogle Fontsから取得し、利用できない場合は端末のフォントに切り替わります。
