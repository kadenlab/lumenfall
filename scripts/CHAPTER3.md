# Chapter 3 — 雪に閉ざされた灯

配布版1.4.0。Chapter 2のミナの「世界の灯を順番に消している。次は雪の山」という台詞と、星硝子が示す白嶺の観測塔を直接引き継ぐ。黒幕の素性は明かさず、大灯の消灯が意図的だったこと、灯が封印も担うことを明らかにする。

## 開始・攻略

Chapter 2クリア後、冒険メニューの「チャプターの記録」から選ぶ。試練の攻略やアクセサリーは不要。各マップの案内ボタン、周辺の案内、白嶺の手帳を利用できる。

1. 白霧の雪原：セナに聞く → 霜喰い → 道標を点灯 → 集落。
2. 凍灯の集落：オル・ユル・ネムの三人に聞く。暖炉で無料全回復。店では既存装備と消耗品を購入できる。
3. 凍れる番人：三行動ごとの氷盾を、星火で崩すか準備・回復で待つ。
4. 凍れる旧都：凍灯兵・白霧の亡影を鎮め、消灯装置の痕跡を調べる。
5. 凍灯聖堂：中央の記録 → 灯狩り → 左右の保温灯 → 炉心。
6. 氷葬の灯守アウレル：星火で大灯の凍結を解除。氷葬・雪崩の「今、防御」を見て身を守る。HP半分で第二形態。雪崩には事前予告と形態移行直後の猶予がある。
7. ボスの会話 → 大灯再点火 → 旧都の三段階点灯 → 世界地図の別の灯が暗くなる → Chapter 3 Complete。クリア後は旧都から再探索・章選択が可能。

宝箱は4個。既存の薬草・星の雫・Gを収録。消耗品は集落の初回会話でも補給。旅立ちの剣・旅人の服、アクセサリーなしで通しクリア確認済み。

## 新敵

| 敵 | 特徴 |
| --- | --- |
| 霜喰い | 二行動ごとの二連撃、剣の威力を軽減する身かわし |
| 凍灯兵 | 氷盾。星火で崩した後の二行動も弱体 |
| 白霧の亡影 | 周期的な霧で剣の威力を25%軽減。魔法は通常 |
| 灯狩り | MP吸収。星火で吸収を阻止し反撃も軽減 |
| 凍れる番人 | 氷盾を持つ門の中ボス |
| 氷葬の灯守 | 二形態、大灯凍結、白夜、予告付き氷葬と雪崩 |

既存ゲームの共有HPを用いるターン制。雪崩もパーティーの共有HPへ作用する。新しいリアルタイム戦闘や操作は追加していない。

## ファイル構成

- `app/chapters/chapter-3/chapter-config.ts`：登録契約、入場・終了フック、BGM。
- `map-config.ts`、`maps/`：5マップを遅延読み込み。scenery.tsは雪・建築・灯の共通部品。
- `terrain.ts`：描画地形と一致する歩行領域・高低差。
- `object-config.ts`：NPC、敵、出口、宝箱。
- `dialogue-config.ts`、`events.ts`、`state.ts`：台詞、進行条件、終了イベント。
- `enemy-config.ts`、`combat.ts`、`sprites.ts`：敵データ、ターン処理、ドット絵。
- `ui.ts`：章専用案内・手帳・開始・終了画面。
- `app/chapters/registry.ts`：軽量メタデータと動的import。
- `app/systems/chapter-unlocks.ts`、`chapter-manager.ts`、`save.ts`：正式なChapter 2クリア判定を使用する解放・移行。
- `app/chapters/types.ts`、`app/game.ts`：章固有の戦闘開始・形態変更・外見変更フックを追加。従来のUI、入力、カメラ、装備、戦闘計算は共通。
- `tests/chapter3.test.mjs`：移行・進行・全マップ到達性・戦闘・アクセサリー・エンディング。
- `docs/`：GitHub Pages用の最新静的ビルド。

## セーブ

version 2と既存キーを維持。version 1の既存移行も維持。`campaign.chapters['chapter-3']`以下にflags、quests、bosses、defeatedEnemies、chests、unlockedAreas、completedを保存。現在章と位置は共通保存に従う。

解放は新フラグの存在ではなく既存`chapter2Cleared`を優先し、古いクリア済みセーブにも追加する。Chapter 3の進行データは初めて入るまで生成しない。試練・装備・HP/MP・経験値・所持品や別管理の設定は初期化しない。正式なChapter 2未クリア状態で偽の解放配列だけ追加しても入れない。

ボス撃破は終了会話より先に保存する。途中で再読み込みした場合は「大灯の記憶」から終了イベントを安全に再開できる。終了会話は報酬を重複付与しない。

## 負荷への配慮

雪はPC220粒、モバイル110粒を一つのPointsで描画し、既存の時刻uniformでGPU側へ動きを移す。毎フレームのVector3・配列生成は追加しない。建物・地形は既存の静的バッチ処理を使用。氷と凍結水路は材質で表現し、新しいReflectorは使わない。灯は既存のPC6／スマホ4灯のプールを利用。章切替で旧マップ、マテリアル、粒子、章のスプライトキャッシュを破棄する。
