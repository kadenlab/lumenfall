# 灯の試練 Ver.1

Chapter 2クリア後、冒険メニューの「灯の試練」から灯守の環へ出発します。既存のクリア済みセーブでも「つづきから」を選ぶだけで解放されます。通知は1回のみです。

## 5つの試練

|試練|勝利条件・ルール|初回報酬|
|---|---|---|
|灯守|灯HPを守る3 Wave。敵の標的を読み、攻撃対象を選択。灯を守ると灯ダメージ90%減|灯守の指輪：防御力+8%|
|残光|15ターン生存。5・9・12ターンに増援|残光のペンダント：攻撃力+8%|
|暗霧|HP・弱点・予告を隠す番獣。灯を掲げると3回の行動選択中に情報開示|霧灯の護符：最大HP+10%|
|無癒|回復禁止の3連戦。HP・MPを引き継ぐ|幻灯の耳飾り：回避率+8ポイント|
|灯喰らい|HP半分で第二形態。灯ゲージ、3ターンごとの大吸光、欠片回収|永灯の首飾り：ターン開始時に最大HPの3%回復|

前の試練をクリアすると次が解放。報酬は初回だけ。ベスト記録は最小ターン数、同数なら残HP最大を採用します。

挑戦時にはHP・MP全快と薬草4、星の雫3を貸与。試練終了・撤退時に本編のHP・MP・所持品へ戻します。連戦の途中では全快しません。中断・再読み込みは祭壇からの再挑戦となり、試練中の貸与品を本編へ持ち出せません。

## アクセサリー

冒険メニューのアクセサリー装備で2枠に装備。本編でも共通効果。同じ品の重複装備は禁止。装備変更でHPは増えません。最大HPが下がる場合だけ現在HPを上限へ丸めます。

元のゲームには防御力数値がなく防具の固定軽減があるため、指輪は固定軽減後のダメージを1/1.08にします。攻撃力補正は剣と星火に適用。回避は主人公への攻撃ごとに8%、灯は回避しません。

リジェネは行動選択が可能になるターン開始時に1回。小数点切り捨て、上限を超えずHP0では発動しません。戦闘終了時は発動しません。無癒ではHP回復・MP回復アイテムと魔法、リジェネをコマンド検証でも禁止します。

## セーブ互換

既存version 2に後方互換のplayer.trialsを追加。セーブキーlumenfall-saveは変更しません。旧version 1移行も維持。章・所持品・設定は初期化しません。

正式判定はcampaign.completedChaptersのchapter-2、またはcampaign.chapters['chapter-2'].completed === true。正式completedがfalseなら到達・ボス情報だけでは解放しません。正式フィールドが存在しない派生記録のみnereis撃破、starGlass、missing-lights完了の3情報を要求します。

trialsにはunlocked、notified、cleared、unlockedTrials、owned、slots[2]、bestを保存。欠損項目を補完し、解放は既存の正式クリア状態から毎回導出します。通知済みは表示時に保存します。

## 主要ファイル

- app/trials/state.ts：移行、解放、報酬、装備、ステータス計算
- app/trials/rules.ts：純粋なターン制ルール、Wave、敵行動、勝敗
- app/trials/chapter.ts / map.ts：遅延ロードする専用エリアとドット絵
- app/trials/ui.ts：試練選択、装備、戦闘情報
- app/game.ts：既存コマンド・演出への接続、試練終了、リジェネ
- app/systems/state.ts / save.ts / chapter-manager.ts：互換フィールドと入口検証
- tests/trials.test.mjs：旧セーブ・解放・報酬・装備・全5試練

水面Reflectorは追加せず、装飾は既存の静的バッチ処理を使います。敵表示は最大6体を開始時に用意して使い回し、毎フレーム処理を増やしません。

## GitHub更新

配布ZIPの中身をリポジトリ直下へ上書き。Pagesはmainの/docsを維持。最新ビルド済みdocsを含むので公開更新のための手元ビルドは不要です。公開URLやブラウザを変えると別の保存領域になるため、既存プレイヤーは従来のURL・ブラウザで「つづきから」を選んでください。

## 検証環境の限界

ブラウザ確認はPC幅と390×740のiframeで実施。後者は同じpointerスティックを表示する検証用CSSを使用します。実機iOS/AndroidのOS操作は未検証です。

確認環境ではWebGLが無効のためCanvas互換描画で進行を確認しています。実機GPUのBloom・影・霧の最終品質や60fpsの実測を保証するものではありません。共通描画エンジン・品質設定は維持しています。

## 2026-09-08 表示・無癒調整

- 生存している敵だけを名前・HP・選択状態付きのカードで表示。敵数を明記し、撃破済みのHP行を除去。
- 弓手・蛾・獣・影の姿を描き分け、敵同士の間隔と試練用カメラを調整。増援／次Waveでは発光、撃破時は姿と影を消してから次の敵へ移る。暗霧の情報制限は維持。
- 第二の試練の15ターン生存と5・9・12ターンの増援は維持。敵がいない間は防御・回復で次の増援を待てると案内。
- 第四の敵HPを200／260／320、攻撃力を18／21／24へ変更。通算3行動ごとに2.4倍の砕灯撃を予告。防御で軽減できる。HP引継ぎ・回復禁止は維持。
- 旧セーブの形式・報酬・装備・クリア記録は変更しない。追加の敵Meshを毎ターン生成せず、最大6体の既存プールとキャッシュ済みスプライトを再利用。
