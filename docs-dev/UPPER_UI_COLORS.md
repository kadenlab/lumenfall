# 上部探索UIの配色・視認性修正

基準main: `a5efc7b7c8a838e4dd32c518033b7d2be7418056`（取得時にorigin/mainと一致）。

## 変更

`app/globals.css` の `.top .tools` と `.quest` 内のボタンに共通の外観を指定。調査用ボタンに専用スタイルがなく、ブラウザ標準の背景に継承した淡い文字色が重なる問題を解消する。

- 通常: 濃紺 `rgba(8,24,36,.92)`、明るい金色文字 `#f0d79a`、金色の枠、控えめな影。
- hover / focus: 少し明るい濃紺とクリーム文字。hoverは対応ポインターに限定し、キーボードfocusには金色の輪郭を表示。
- active: 背景を明るくし、内側の影で押下を表現。
- disabled: 暗い濃紺、彩度を落とした灰色文字 `#a5b2b6` と枠。ボタン全体を薄くせず文字の可読性を維持。
- `appearance:none` / `-webkit-appearance:none` で標準ボタン外観を抑止。

位置・サイズ用CSS、ボタン処理、会話・メニュー・戦闘UI、カメラ、セーブ仕様、依存関係は変更なし。今後も同じ探索HUD領域内のボタンに適用される。
